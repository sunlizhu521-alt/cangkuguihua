# 仓库分布分析系统

这是一个面向跨境仓库分布与调拨决策的纯前端分析工具。业务文件、映射、报价、服务密钥和测算结果默认保存在本机浏览器；仓库报价只有在用户审核确认后才会进入正式测算。

## 已实现能力

- 11个事实表和维度表文件槽位、自动表头识别、中文字段映射与缺失校验。
- 在库成品调拨口径、45天默认分析期、日均预测、同区域调拨限制和整箱数量搜索。
- 四个独立仓库报价槽位，保留来源工作表、单元格、原文、可信程度及校验结果。
- OpenAI、DeepSeek和Cloudflare转发服务配置；密钥不写入代码、Git或导出文件。
- 自行寻找中转报价、全包价去重、人民币与美元换算、物流商完整报价方案比较。
- 美国美西、美中、美东历史需求热力、仓库位置、建议库存分布和邮编覆盖率。
- 完整中文Excel分析与审计导出。

## 本地运行

```bash
npm install
npm run dev
```

测试与构建：

```bash
npm test
npm run build
```

## Cloudflare转发服务

转发服务位于 `worker` 目录。部署前修改 `worker/wrangler.toml` 的允许来源，然后在已登录Cloudflare的环境执行：

```bash
cd worker
npm install
npm run deploy
```

转发服务只在一次请求期间转交密钥与已筛选报价内容，不写入数据库、缓存或日志。前端仍会对返回费用结构再次校验，审核确认后才应用。
